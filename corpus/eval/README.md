# corpus/eval

Topics: `corpus:eval`.

The in-module evaluator: compile and run-time errors, evaluated fns called from compiled code, the core table, core macros as built-ins, namespaces, the reader, special forms and whole programs (`program/`). `native-ledger.md` records the evaluator on its native seam. Run by `checks/run-corpus.sh` over the subdirectories.
