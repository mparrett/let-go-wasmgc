The compiler here is the backend's own source (src/ of the repository), compiled by the native backend into one module; your program's forms go through the same analysis, shake and emission as natively, inside that module. The text it emits is assembled by wasm-tools' own parser (the wat crate) compiled to wasm, so the bytes are what wasm-tools parse gives for the same text. What the backend cannot compile yet (a defmulti, a type definition in the program's own namespace, a ratio) stops the compiler pane with its named limit, as the native driver stops. Programs that read keys or files have no keyboard or file system here.
