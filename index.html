let-go-wasmgc let-go compiled to WebAssembly GC, running in this tab

An experimental backend compiles let-go's optimizer IR straight to WasmGC, with the runtime and an evaluator written in let-go and compiled the same way. Stock lg -w ships the bytecode VM inside wasm; these modules contain no VM. Each demo below is one small module. Needs a browser with WasmGC and JSPI: Chrome or Edge 137 or newer on desktop. Firefox, Safari and every iOS browser lack JSPI as of 2026-10-02, so the demos stop with a message there. The pages fetch nothing but the module and, for the editors, xterm.js.

let-go REPL

A read-eval-print loop in the module. The evaluator handles the special forms, the core macros and about 230 core functions; pick an example from the menu or type your own.

77 KB brotli, as of 2026-10-02

eval vs compiled

Type a form and see what the module's evaluator returns and what its emitter's compiled code returns, linked into the running module, with the compiled module's sections and bytes.

136 KB brotli, as of 2026-10-05

xsofy

A roguelike, its real main.lg compiled by the backend and rendered through the game's own shell. World generation is byte-identical to native lg for seeds 1 to 20.

147 KB brotli, as of 2026-10-02

legmacs

An Emacs-like editor written in let-go. Type a defn into *scratch* and evaluate it with C-x C-e; the evaluator runs inside the module. Quit with C-x C-c.

178 KB brotli, as of 2026-10-02
