# DECISIONS (orchestrator-owned; D1–D9 are in the plan, section 3)

- 2026-09-30 D10. Module layout: one wasm module per program; the runtime WAT is prepended as text by the driver (as the probe does) until Phase 2 turns it into generated sections. Exports: `_main` (runs top-level forms in order) plus every defn by name.
- 2026-09-30 D11. Host imports for Phase 1 are exactly: `env.print_i64`, `env.print_str` (utf-8 ptr+len or array ref), `env.print_nl`; everything a scalar program prints goes through them. Phase 2 replaces them with `str`/`pr-str` in the runtime and one `env.write` import.
- 2026-09-30 D12. The runner `checks/wasm-run.sh <prog.lg>` compiles with the driver, assembles with wasm-tools, runs under node, and mirrors lg's observable behaviour: program stdout to stdout, exit 0 on success, non-zero with an `error: <message>` first line on an uncaught exception (so oracle.sh's normalised comparison works).
- 2026-09-30 D13. `.expected` files beside corpus programs are snapshots of native lg's stdout; `run-corpus.sh` fails STALE-EXPECTED if native lg no longer produces them, THEN calls oracle.sh. oracle.sh itself never reads them. Catches hand edits and lg drift the oracle would silently follow.
- 2026-09-30 D14. run-corpus.sh exit precedence: any MISMATCH or STALE → 1; otherwise anything short of all-MATCH (NOT IMPLEMENTED) → 2; all MATCH → 0.
- 2026-09-30 D15. `/` on ints yields ratios and, for MinInt64/-1, a bigint. Those are runtime value types (Phase 2). The div-*.lg op-matrix programs are skipped by P1.1 (run-corpus.sh honours a `SKIP` file in the corpus dir listing basenames) and re-enter at P2.7. `quot` stays in Phase 1.
- 2026-09-30 D16. Native quirks the backend must reproduce, not fix: (quot MinInt64 -1) = MinInt64; (- MinInt64) = MinInt64 while (- MinInt64 1) and (dec MinInt64) throw; shift counts ≥ 64 or negative follow Go (0 or sign), never throw; overflow message carries an `ExecutionError:` prefix, divide-by-zero does not.
- 2026-09-30 D17. P1.1's programs wrap every application in try/catch, so P1.1 cannot go green before P1.2 lands `:try`. Order within Phase 1 is therefore P1.0 → P1.2 → P1.1 ∥ P1.3 ∥ P1.4.
- 2026-09-30 D18. Hash hook contract: `checks/wasm-hash.sh <edn> <kind>` prints one decimal uint32. `<kind>` is required because `[]` hashes differently as ArrayVector vs PersistentVector. Non-finite floats are spelled `##NaN` `##Inf` `##-Inf` in vectors.tsv.
- 2026-09-30 D19. The wasm port reproduces let-go's hashing bit for bit INCLUDING its quirks (see FINDINGS.md H1–H5): empty-seq/[] split, -0.0 ≠ 0.0 hash, map entry hash = hash(k) ^ hash(v), the shared 64-bit finalizer across Int/Char/Float/BigInt, keyword = symbol + 0x9e3779b9. Parity first; fixing them is an upstream conversation after the campaign, phrased as plain hashing bugs.
- 2026-09-30 D20. Macroexpansion leaves qualified heads (`core/<`, `core/inc`); ir.build keeps them as var calls. The backend lowers calls whose target var is one of `#'< <= > >= + - * inc dec` as the matching IR op. `=` stays a call (polymorphic).
- 2026-09-30 D21. Legalize threads `:load-var` through blocks as block-args; values `ir/resolve-single-source` resolves to a var get no local and no edge copy and lower only in callee position; dead `:invalid` block params get no copy. A var used as a VALUE is an error until P1.3 (var table).
- 2026-09-30 D22. Booleans box to two `$Bool` singleton globals. Ints still box to `$Int` structs; the hybrid i31 of D2 is an explicit P1.1/P1.3 follow-up, not done in P1.0.
- 2026-09-30 D23. Driver: every defn body goes through `ir.passes.pipeline/expand-all` before `build-fn` (build-fn does not macroexpand). `ns`/`defn` forms are eval'd in a `user` ns so vars resolve; other `def*` heads are a named error; remaining top-level forms run in order in `_main`.
- 2026-10-01 D24. Intrinsics (`rt/wasm/intrinsics.lg`, ns `wasm.intrinsics`, 42 fns + `defstruct`/`defarray`/`deffunc`): the wasm instruction and typeinfer signature live in `:wasm`/`:type` var metadata so the backend and the coverage test read them mechanically. Operands/results are lg types (`:int`=i64, `:bool`=i32, `:any`=(ref null eq)); i32/i8 are storage only and each intrinsic's expansion carries its own wrap/extend. Mutable fields are `[:mut t]`. `new`/`call-ref` arity is fixed by the declaration.
- 2026-10-01 D25. No `wasm/throw`/`wasm/try`: lg `try` + `core/throw` (P1.2) for catchable errors; `wasm/trap` (uncatchable) for internal invariants. All runtime types go in ONE `(rec ...)` group so same-shaped structs stay distinct under `ref.test`.
- 2026-10-01 D26. Reference impl is stricter than wasm where wasm is silent (out-of-range i31, index ≥ 2^32, raw lg value in a :ref slot, out-of-range :i32 all throw). OPEN for the backend: bounds-check indices in i64 or accept the i32-wrap divergence; decide at P2.1-backend.
- 2026-10-01 D27. Host calls in the reference are deterministic (virtual clock advanced only by host-sleep; env from `*host-env*`). `bytes-of-string` is literal-only in wasm (`array.new_data`).
- 2026-10-01 D28. Gap: float hashing needs `f64-bits` (`i64.reinterpret_f64`), absent from the set and not computable in native lg without interop. P2.2-wasm adds the intrinsic; the reference impl may use a Go-side helper via a tiny native, or skip float rows under `--native`.
- 2026-10-01 D29. Map order spec = `corpus/maporder/SPEC.md` (let-go 4e769212): insertion-ordered array-map up to 8 entries (`arrayMapMaxEntries`, persistent_map.go:601) incl. `hash-map`; 9th key promotes to a 32-way HAMT (bitmap + collision nodes only, low 5 bits first, seq walks slots 0..31 depth-first); never demotes; sets are hash-ordered at every size. The port implements the node algorithms literally; collision-bucket order is history-dependent.
- 2026-10-01 D30. Parity includes the bucket 2→1 dissoc bug (FINDINGS M1). Go-map-sourced maps (json, transit, bencode, boxing) are out of the oracle's scope. maporder rows above 100 keys print head 16, tail 16 and a checksum.
- 2026-10-01 D31. Exceptions: try regions are lambda-lifted wasm functions; ONE tag `$lgex (param (ref null eq))` carries the thrown lg value; runtime errors are `$Err` kind 1 (uncaught message) reified to kind 2 on catch (`ex-message` then carries the `ExecutionError: ` prefix for overflow, none for divide-by-zero, as native); finally = catch_all_ref + throw_ref. Catch class table is strict (Throwable, Exception, ExceptionInfo, String + java./clojure.lang. spellings); other classes are compile errors.
- 2026-10-01 D32. The structurize gate rejects only trees containing a `:goto` node; `:multi`-exit loops are complete and lower (`:break` finds its loop by exit block). P1.6's metric is therefore `:goto` count, and `:switch` nodes (keyword cond chains) are P1.6's remaining work.
- 2026-10-01 D33. run.mjs runs the module on a worker thread with a 256 MB stack (native lg recurses past 3M frames; 100k-deep int recursion must not die). P1.GATE's timing compares like with like.
- 2026-10-01 D34. CONFLICT TO RESOLVE at P2.1-backend: P1.2 emits every wasm type as its own rec group (relying on structural distinctness); D25 requires ONE rec group. Move to one rec group when the intrinsics' `defstruct` types are emitted; until then new Phase-1 types ($Kw, $Map0, $Err) must stay structurally distinct.
- 2026-10-01 D35. Unary minus: build.lg turns `(- x)` into `(sub 0 x)` so `(- MinInt64)` throws in the IR path while native bytecode wraps (D16). Not distinguishable after build. Parity choice: the DRIVER rewrites unary `(- x)` to the unchecked form before build (what native does), documented; lower-go has the same divergence (upstream finding).
- 2026-10-01 D36. Closure ABI (adopted from P2.5's proposal; P1.3 implements it): a closure is an `Fn` struct with one funcref per arity (0, 1, 2, … as needed, plus a variadic slot later) and an env field; each funcref takes the closure itself as first argument. The runtime calls closures only through `invoke0/1/2…` helpers.
- 2026-10-01 D37. Native calling convention: runtime natives take and return refs (ints boxed, booleans as the Bool singletons); typed fast paths are the backend's business at the call site. Known exception: `nth`'s index is an i64.
- 2026-10-01 D38. Value-model stand-ins are UNIFIED NOW, not at P2.2: boxed values are structs in the single rec group (D25): `Int{i64}`, `Bool` singletons, `Float{f64}`, `Str{bytes, cached-hash}`, `Kw{ns name hash}` and `Sym{…}` interned, `Char{i32}`, `Nil` = ref.null. `rt/wasm/seq.lg`'s Int/Bool boxes are the reference; phm's `vstub` HostVal side table is a test-only shim to be removed when P2.4-hamt lands (its author gets this message). Equality and hash of every box follow corpus/hash/SPEC.md.
- 2026-10-01 D39. One runtime global per namespace is allowed (`hooks`), since the backend cannot lower top-level `def` yet (D23); P1.3's var table lifts that.
- 2026-10-01 D40. Runner: `checks/intrinsics-native-runner.lg` takes its namespaces from the `.sh`, one per `corpus/intrinsics/*_test.lg`; the deftest-count guard stays.
- 2026-10-01 D41. (amends D22) Ints box hybrid: `ref.i31` when the value fits 31 bits signed, else `$Int`; the form is canonical (an in-range int is never a `$Int`), so equality/hash may rely on it. Box inline in program fns, keep box/unbox as calls inside runtime helpers (V8 inlining budget; measured fib(32) 22.2 → 15.5 ms).
- 2026-10-01 D42. Boxed non-Int operands: bit ops reproduce native's text (`bit-and expected Int`); numeric ops throw the named limit `lower-wasm: <op> on a non-Int operand (numeric tower is Phase 2)` until P2's numeric tower; no bare `ref.cast` traps on the boxed path.
- 2026-10-01 D43. quot: divisor -1 emits `0 - a` (i64.div_s traps on MinInt64/-1, native returns MinInt64); zero divisor throws `divide by zero` unprefixed. Shifts: `select(op, fallback, b <u 64)` with fallback 0 / `shr_s a 63`.
- 2026-10-01 D44. The opmatrix "typed" half is constant-folded by optimize-fn; `corpus/typed/typed-probe.lg` (loop-counter operands, 1808 lines, ~28 s to compile) is the real typed-path check and is part of P1.1's row.
- 2026-10-01 D45. Float formatting (closes plan open question 7): a dialect port of Go's strconv `decimal` (exact, table-free) + Go 1.26 `roundShortest` for `'g',-1`; integral values use `'f',1`. 281/281 corpus lines byte-exact, 10k random doubles 0 mismatches. `float-bits` is a stand-in for the `f64-bits` intrinsic (D28); P2.2-wasm replaces its body and removes str.lg's single `/` whitelist.
- 2026-10-01 D46. Strings: UTF-8 bytes; `count`/`seq`/`subs`/`index-of` are rune-indexed, `compare`/`=`/hash are byte-wise, `nth` is byte-bounded but rune-walking (native quirk, reproduced). Escapes per STR.md (`\uXXXX` uppercase for other controls; surrogates print U+FFFD). Keywords/symbols are interned in wasm.str's table, split at the first `/`, compared by text.
- 2026-10-01 D47. Error messages that embed a value or type name stay static traps until ex-info strings exist (P2.7); tests assert both sides throw.
- 2026-10-01 D48. Runtime integration item (P2.9, new row): apply STR.md's seq.lg patch (move Str/Char/Kw/Sym/Float structs beside Int/Bool, extend `kind`, string-aware seq/count/nth in seq.lg, scalar cases in equiv?/hash*), replace the single foreign-hook slot with per-kind hooks, remove phm's vstub, and make all `rt/wasm/*.lg` load as one runtime under native lg. Runs after P2.4-hamt reports.
- 2026-10-01 D49. (amends D29/SPEC.md) A transient that drains to 0 and regrows inside the same transient stays in HAMT order even at ≤ 8 keys (`transient.go:119-140` never clears `t.hamt`); only persisting right after draining yields the empty ordered map. phm mirrors it; the corpus adds a transient-drain-regrow row at P2.9.
- 2026-10-01 D50. Map/set natives take `:int`/`:bool` where Go's do and box only at the hook boundary (narrowing D37 for collections). Collision lookup ignores the hash and `nil`/`()` are one key (valueEquiv), both mirrored.
- 2026-10-01 D51. The native runtime check is split: default tier must finish under 90 s; the 10k-size map/set tiers and the 48 s seq realisation sweep move behind `SLOW=1`. `checks/gate.sh 2` runs both tiers.
- 2026-10-01 D52. `$Fn` layout (final; seq.lg's `defstruct Fn` grows to match at P2.9): fields 0–2 typed code refs `$Code0..2` (closure first, then boxed args, boxed result), field 3 env (per-closure `$Env_*` struct or null; capture-free closures are one immutable global), fields 4–5 `$Code3..4`, field 6 `$FnInfo{kind i32, arity i32, name bytes|null}`. Unknown callees go through `$rt_invoke0..4`; >4 args and variadics are named errors (xsofy: 9 of ~1107 fn heads use `&`; anonymous arities top out at 4).
- 2026-10-01 D53. A minimal `$Atom` (atom/deref/reset!/swap!) is in Phase 1 because the `fn` macro expands named fns through an atom; validators, watches and printing stay P2.7.
- 2026-10-01 D54. Var table: one mutable `$var_<name>` global per top-level def/declare var, read at the `:load-var`; defn and core-op vars are constants materialised as static `$Fn` globals when used as values; core ops as values support only the IR op's arity. Top-level `(def x v)` runs inside `_main`; a var both defn'd and def'd is a named error.
- 2026-10-01 D55. (amends D13) Uncaught-error programs whose native report embeds a heap address carry no `.expected`; oracle.sh's normalisation still compares the message.
- 2026-10-01 D56. Error-message parity: `function <fn [name ]0x..> expected A args, got N`, `<mfn NAME 0x..> doesn't have a N-arity variant`, `TypeError: <let-go.lang.X> is not a function ` (trailing space); caught messages gain `ExecutionError: `. Native's def-naming rule for fns is reproduced by the driver.
- 2026-10-01 D57. Timing, 1e7 calls: direct 83 ms, capture-free closure value 105 ms, defn-as-value 140 ms, capturing closure 181 ms. Inlining `$rt_invoke` at call sites is the next perf step, not scheduled.
- 2026-10-01 D58. Twin markers: a runtime defn claims the native(s) it implements with `^{:twin "core/first"}` (or a vector) on its name, read from source by `tools/twin-manifest.lg`; a twin covers every var bound to the same NativeFn. `checks/native-twins.sh` is the Phase 2/3 scoreboard; `tools/native-inventory.lg` (954 natives, 63 ns at 4e769212) is rerun when lg moves. IR-op natives (`+ - < …`) need a twin only as VALUES. term/* is excluded from P2.8 (Phase 4).
- 2026-10-01 D59. Hook ABI: seq.lg holds three Handler slots `[pred seq count equiv hash]` (0 maps, 1 sets, 2 generic), set with `set-kind-hooks!`; `phs/install-hooks!` links maps and sets. All box structs, FnInfo and Code3/4 live in seq.lg; str.lg keeps one-line aliases. Twin markers go on seq.lg's dispatching entries only.
- 2026-10-01 D60. (amends D51) Default tier: 1000-key maps run only assoc/transient/dissoc-half; `SLOW=1` is the superset and `gate.sh 2` sets it. Measured 68–79 s default, ~3.5 min slow.
- 2026-10-01 D61. NaN: `equiv?` checks scalars before the identity fast path and phm's key-equiv skips identity for Floats, so a NaN box is never `=` to itself (Go parity; a latent bug fixed).
- 2026-10-01 D62. PHASE 1 GATE PASSED 2026-10-01 (verified by the orchestrator: P1.0–P1.6 ok; fib(32) backend 12.85 ms vs probe 9.28 ms = 1.385×, limit 1.5, checked arithmetic kept).
- 2026-10-01 D63. Unknown vars compile through nil var-table slots (`$ext_*`) and fail at run time with native's `TypeError: nil is not a function `; the census counts them `unbound-var`. Phase-2 constants (vector/map/set/char/float/list/regex/quoted symbol/#'var) compile to a named run-time throw `lower-wasm: Phase-2 constant <kind>`. `:div` is exact-int only.
- 2026-10-01 D64. `session-module` tree-shakes unreferenced runtime functions (types, globals, data stay). Self-recursive defns are typed optimistically via `*declared-return-types*` (#599) and kept typed only if every return is `:int` (sound by induction), else rebuilt boxed. Together these took fib from ~2.0× to 1.39×: V8's inlining budget scales down with module size, so module size is a perf input.
- 2026-10-01 D65. `:switch` lowers as an if-chain via `$rt_kw_is` (br_table waits for interned keywords). A keyword cond inside a loop body is not folded by structurize and lowers through `=`, which throws on keywords until Phase 2's generic `=` lands.
- 2026-10-01 D66. Census (xsofy 1064 units, legmacs 816): compile rate 1055/1064 and 813/816; 0 unsupported ops, 0 goto, 0 unsupported tree nodes. Dominant bucket is `unbound-var` (969 / 686), i.e. the runtime surface, as predicted. Full fresh census ~30 min on a loaded host; TSVs are cached by mtime, `FRESH=1` reruns.
- 2026-10-01 D67. Kinds 23 MapEntry, 24 Atom, 25 Volatile, 26 Err in seq.lg; `wasm.core/ckind` refines the foreign kind into 30–36 (map, set, three transients, type, meta'd keyword/symbol). A 4th hook slot carries printing with a mode integer (0 str, 1 pr-str, 2 print-str); `value-string` feeds hashing of printed-form kinds (S1).
- 2026-10-01 D68. Raise convention: runtime errors are `(throw (Err kind msg cmsg data cause))`; the backend's `$Err` gains field 4 (cause) and lowers `#'throw` to the wasm throw. Backend bug to fix at P2.1-backend: `$rt_ex_message` must return the string form of a non-exception (`(ex-message 5)` = "5").
- 2026-10-01 D69. Twin markers for conj/nth/peek/pop/compare live on wasm.core's dispatchers (amends D59).
